# ESV Bible (personal offline app)

A minimalist, offline-first Bible reader built as a web app (PWA): reading, highlights and tags, notes,
a daily reading habit tracker with a journal, a prayer list, and search across everything.

This repository contains **only the app code**. It does not include any Scripture text. On first launch the app
asks you to choose your own licensed `esv.json` data file, which is then stored on your device only.
Your highlights, notes, journal and prayers also stay on your device.
